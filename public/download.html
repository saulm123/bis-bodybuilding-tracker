Free macro, training and health tracker. No account, no ads, everything stays on your phone.

Download for Android

Installing on Android
  1. Tap Download for Android and open the file when it's done.
  2. If asked, allow your browser to install unknown apps.
  3. If Google Play Protect warns about an unknown app, tap More details → Install anyway. That's because it isn't from the Play Store.

Want automatic updates? Install Obtainium and add github.com/saulm123/bis-bodybuilding-tracker.

Use the web version instead (iPhone too)

iPhone: open the web version in Safari → Share → Add to Home Screen.
